# Zanop Kernel v0.0.6 Release Facts
- **Version:** v0.0.6
- **ECMXS:** The English Commands Mixed Set (Zanop Shell) command vocabulary is documented from the sibling `zanop-ecxms` project. These reference commands are not necessarily implemented by the kernel's built-in shell; the ECMXS project describes its `.esh` shell as planned for a later Zanop OS release.
- **GUI support:** The intended desktop environments are modified LXQt and modified Budgie only. These Zanop-modified versions omit the familiar Linux branding/signs. This does not indicate support for standard upstream desktop distributions.
- **ZFS:** ZFS is not implemented in this kernel. Do not claim that the kernel can mount or manage ZFS pools; that requires a compatible filesystem implementation and storage integration.
