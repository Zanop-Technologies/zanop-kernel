# Zanop Kernel

The Zanop OS kernel — written in Rust with Assembly for low-level
architecture code (boot, interrupts, context switches).

## Support

This kernel currently supports **terminal (text-mode) output only**.
There is no graphical display support at this stage — all output
and interaction happens through a serial/VGA text console.
